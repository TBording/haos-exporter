# App artwork

- `icon.svg` is the source of the app folder's `icon.png` (128×128).
- `logo.png` (250×100) is the same glyph without its background square, on a
  matching slate gradient, with a "HAOS" + app-name wordmark in the system sans-serif.

Original artwork for this project; it uses no third-party logos.
Rendered with headless Chromium (Playwright), PNG with transparent corners.
